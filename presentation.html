ERP Student Management System

A full-stack role-based platform for managing students, attendance, results, and leave

MongoDB Express.js React Node.js JWT Auth Bootstrap

Presentation — July 2026

Project Overview

A comprehensive ERP system for educational institutions with role-based access

Three-Role System

Admin, Staff (department-specific), and Student logins with JWT-based authentication and route protection.

Department Isolation

Staff members see only their own department's students, attendance, results, and leave applications.

Full CRUD Operations

Complete Create, Read, Update, Delete for students, attendance records, results, events, and leaves.

Reporting & Export

PDF marksheet generation, Excel export for students, attendance, and results data.

Key Features

Detailed breakdown of each module

📋 Attendance

Day-by-day with date picker. Mark Present/Absent/On Duty with reasons. Stats per day. Low-attendance (<75%) tracking. Excel export.

📊 Results

Dynamic subjects per semester (1-8). Auto-grade calculation (O/A+/A/B+/B/C/RA). GPA computation. Student view shows grade & GPA only (no marks). PDF marksheet.

📅 Leave Management

Student: apply with date range & reason. History with status badges. Staff: approve/reject. Department-filtered for staff.

🎯 Events & Activities

Admin: add/delete events and activities. Public: Home page shows upcoming. Filtered by category. Location for events, department for activities.

📈 Admin Dashboard

Stats: total students, departments, attendance records, results. Pie/bar charts (Recharts). Department-wise distribution. Pass/fail counts. Manage events/activities inline.

🔒 Security

JWT-based authentication. Role-based route protection. bcrypt password hashing. Department-level data isolation for staff. Axios interceptors for auto token attachment.
