
# ERP-Based Integrated Student Management System

 Project Description

The **ERP-Based Integrated Student Management System** is a web-based application developed to simplify and automate the management of student information within an educational institution. The system replaces manual record keeping with a centralized digital platform, making student data management faster, more accurate, and more secure.

This project is developed using the **MERN Stack**:

* **MongoDB** – Database
* **Express.js** – Backend Framework
* **React.js** – Frontend
* **Node.js** – Server Environment

The system provides different modules to manage student records, attendance, academic results, and dashboard analytics. Administrators can add, update, delete, search, and view student details easily. Attendance can be recorded digitally, and result management includes GPA, percentage, and grade calculation. The dashboard provides real-time statistics and graphical reports to help administrators monitor institutional performance.


Objectives

* Automate student information management.
* Reduce paperwork and manual errors.
* Maintain a centralized database.
* Improve data accuracy and security.
* Provide real-time reports and analytics.
* Simplify attendance and result management.


# Modules Included

 1. Dashboard Module

* Displays total students
* Attendance statistics
* Result statistics
* Pass percentage
* Department-wise student chart
* Recent activities
* Upcoming events
* Announcements


 2. Student Management Module

* Add Student
* View Students
* Update Student
* Delete Student
* Search Student
* Department Filter
* Export Student List to Excel

 3. Attendance Management Module

* Mark Attendance
* Present / Absent / On Duty
* Attendance Percentage
* Low Attendance Alert
* Monthly Attendance Report
* Department-wise Attendance Statistics
* Export Attendance Report to Excel

 4. Result Management Module

* Add Student Results
* GPA Calculation
* Percentage Calculation
* Grade Calculation
* Generate PDF Marksheet
* Export Results to Excel
